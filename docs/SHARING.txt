文献阅读器 0.6.15 · 同事本地分享版

本版更新
· 原文脚注和尾注可从能确认的正文注号打开，并返回正文阅读位置。
· 改进连续正文、跨页段落、文首信息和页边版式的识别。
· 有可靠 PDF 字形证据时恢复连字、重音和词距；重新转换时保护已有译文、批注和来源定位。
· 无法安全迁移的正文页保留旧版，任务结果会说明；复杂版式仍需核对 PDF 原件。

Windows 10/11（64位）
1. 解压 PaperReader-Windows-0.6.15.zip，双击「文献阅读器.exe」。
2. 程序在本机启动，自动在默认浏览器打开阅读界面。无需安装 Python 或 Node.js。
3. 第一次启动可能需要等十几秒。退出请用「设置 → 退出阅读器」；关闭浏览器标签页不会退出后台。

Mac（Apple芯片及Intel）
1. 用 Finder 解压 PaperReader-macOS-0.6.15.zip。
2. 把「文献阅读器.app」拖到「应用程序」或自己的文件夹，双击打开。
3. 内含两种芯片的运行环境，不需要安装 Python、Node.js 或 Rosetta。
4. 此版本未签名/公证。如 macOS 阻止打开，请按系统提示在「系统设置 → 隐私与安全性」允许本次打开；不要关闭系统安全保护。
5. 此Mac包在Windows上组装并检查内容，尚未经真实Mac运行验证。Mac暂不支持扫描件OCR；有文字的PDF可正常导入阅读。

开始使用
打开后是空文献库。拖入自己的 PDF，即可阅读、搜索、标注、做笔记和导出。
程序只监听本机 127.0.0.1，不需要搭建服务器，不提供局域网共享或云同步。
默认关闭导入时的联网书目补全；如需使用，可在「设置 → 导入与命名」开启。
Windows OCR使用系统已安装语言包，不上传扫描件。复杂排版、公式及识别结果请与原件核对。

从旧版升级
先在「设置 → 备份与迁移」保存一份备份，再从旧界面的「设置 → 退出阅读器」关闭服务，打开新版程序。
新版继续使用自己电脑上的原文献库，不需要重新导入论文。
已有文献要使用本版文字提取与版面处理时，打开后点击「重新转换 HTML」，在任务面板查看处理结果并对照 PDF 核对。

AI 功能（按需设置）
分享包不含任何人的 API Key，不含本地大模型权重。
· 使用 OpenAI 或 DeepSeek：在「设置 → 模型与翻译」填写自己的 Key 和模型名称。
· 使用本地模型：自行安装并运行 Ollama，下载模型，然后填写已安装的模型名和地址（通常 http://127.0.0.1:11434）。
· 不配置 AI 也能管理和阅读 PDF、标注、做笔记、搜索及导出。AI 翻译、摘要和问答需要可用模型。
· 选择云端模型执行任务时，相关文献内容会发送给该服务；本地模型任务不自动切换到云端。
· Windows 密钥使用当前用户系统加密；Mac 密钥存入当前用户的登录钥匙串。

你的文献存在哪里
Windows：%LOCALAPPDATA%\PaperReader\data
Mac：~/Library/Application Support/PaperReader/data
程序升级或换一个程序文件夹不会清空文献。不同系统用户各自拥有独立文献库。
在「设置 → 备份与迁移」创建备份再迁移；备份不包含 API Key 或本地模型。
启动日志位于上述 data 文件夹中的 reader.log，任务日志为 jobs.log。
